## For Mr. Pina

1. **Publish v0.4.3.** Open https://github.com/pina-hash/idea-armory/releases/new, click **Choose a tag**, type `v0.4.3`, click **Create new tag: v0.4.3 on publish**, leave **Target** on `main`. In **Release title** type `IDEA Armory v0.4.3`, leave the description empty, leave **Set as the latest release** checked, click **Publish release**. The **Agent release** workflow attaches the files in about 40 minutes; computers on 0.4.1 or 0.4.2 update by themselves.
2. **Lab computers still on 0.3.x** need `IDEAArmory-win-Setup.exe` from the v0.4.3 release run once, under each Windows account that uses Armory (flash drive; at "Windows protected your PC" click **More info**, then **Run anyway**).
3. **Check a computer's version:** open Armory, **Settings**, "About this Armory".
4. **Rename the lab computers** (idea-armory `docs/LAB_COMPUTER_NAMES.md`): copy the four files in `tools/lab-names/` to a flash drive; at each computer, signed in as an administrator, double-click **Rename this computer.cmd**, click **Yes**, press **Enter** for the suggested name (or type one), and it restarts. `names-done.csv` on the drive lists every computer. Afterwards a student signs out of Armory and connects again for the website to show the new name.
