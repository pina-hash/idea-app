The Plate's `--plate-label-size` reads `--fs-micro` (said once). StatusChip's size reads the same token. The launcher (`src/lib/AppLauncher.svelte`) was left alone: lane 0472 owned it on the day.
- THE KIT'S LABEL PARTS (tools/hx-kit/ belongs to the HTML standards chat; this lane may edit only `kit/plate.css`): `.idea-plate` declares `--plate-label-size: 0.6875rem`, and the eyebrow, chip, select word, pad and display label read it, each with the same 11px fallback, so an assignment's labels and the site's stand on one floor.
- THE DARK THEMES' SECONDARY INK AND DONE GREEN, LIFTED TO THE NOTEBOOK GRID'S INKS. `--text-2` from `#9aa49d` to `#b4bdb7` on IDEA and Space White's dark rooms (OKLCH lightness 0.71 to 0.79, hue and chroma held, 5.88 to 7.84:1 on `--bg1`), Matrix's from `#8fae94` to `#a4c4a9`; `--status-ok` on the dark themes is `--nb-cell-ontime` (`#86bf7e`, the brand green's hue lighter). The warning and danger inks needed nothing: 0465 solved them past the grid's. `tests/color-tokens.test.ts` holds the new rule (same hue, no more chroma, lighter; a positive control on the warning hue).
- 44px CONTROLS. One zero-specificity rule in `src/lib/classroom/plate.css` gives every button, select and one-line field on the plate a 44px minimum height and every button a 44px minimum width, written as `calc-size()` and never a bare length. **It took three tries and the checks caught each one.** Bare lengths: a length replaces a flex item's automatic minimum, so a key in a flex row could shrink below its own words; Take the tour shrank to 93px of its 122 in the home header's held-on-one-line measurement, the header's fit concluded the Install app key's word fitted at 375, and the header wrapped 52px when the key arrived, and the same shrink put the grading console's Close past its own edge. A `min-content` basis for both: it also stops a full-width button narrowing, and My coins' rule list ran 89px off a phone. An `auto` basis for both: measured in this Chromium, it does not hold a SHRINKING flex item, so eight colour swatches fell to 25.6px and the notebook's Edit to 22.6px. What shipped is `calc-size(auto, max(44px, size))` for the height and `calc-size(min-content, max(44px, size))` for the width, with `Disclosure.svelte`'s full-width trigger declaring `min-width: auto` for itself. A scratch page in the same Chromium read a flex item keeping its 88px of words, a full-width button in a 200px box staying 200px under `auto` (352px under `min-content`), and a one-letter key at 44px. **And the selector itself bit once**: inside `@scope (.cr-plate, .site-plate)`, `.cr-plate button` is relative to the scope root and asks for a second plate inside the first, so it matched nothing; the rules name the root as `:scope.cr-plate` (the class is how `tests/no-global-document-lock.test.ts` tells a rule that stays on its page). A control that is a deliberate exception says so on itself (`data-tap-floor="24"`, the class list's row checkbox, arrow and menu), a scale drawing on its root (`data-scale-drawing`, the Maps plan and elevation), and a miniature of text (`data-miniature`, a notebook entry's thumbnail). Plus the per-surface fixes: the class list's row menu items (36 to 44px), the home header's emblem and Sign in and the footer archive link, the calendar week strip's 24px rows, pressable StatusChips reaching 44px with `.tap-reach-44`, and a dozen keys across certifications, coins, Foundry, Maps, notebook and tournaments.
- 24px INLINE LINKS. A plain link in a paragraph, definition or caption on the plate gets block padding to a 24px line, which grows the target without moving a line of text.
- 72-CHARACTER PROSE. `--measure-prose: 72ch` (`effects.css`) caps every paragraph, definition, quote and caption on the plate, never the card around it, so the card keeps the page's right edge. A page title block and a `/dev` harness's own notes are left out.
