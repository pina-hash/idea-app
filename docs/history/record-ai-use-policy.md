`docs/policy/IDEA_AI_Use_Policy.md` (pathway-wide) and
`docs/policy/IDEA209H_AI_Policy_Quick_Reference.md` (standalone instructor copy)
govern how AI may be used in producing student work across the IDEA courses:
the four-level badge (OFF / COACH / ASSIST / OPEN), the two-part Declaration
(integrity checkbox + AI disclosure) every assignment carries, and the
per-category defaults. **When building a new assignment, the AI-level for
each module is set by asking the instructor, never inferred from the content
alone.** The category-defaults table in `IDEA_AI_Use_Policy.md` ("Category
Defaults") is the starting point for that conversation, not a rule that
self-applies.
