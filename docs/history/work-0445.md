Two follow-ups to ledger 0443 from Mr. Pina.

1. `tools/hx-kit/test.mjs`'s "Take photo opens the camera" gate failed on the starter in a stock Playwright 1.56 Chromium: `tap()` delivered a touchend but Chrome never sent the click, so no file chooser opened; `click()` passed. The gate now taps, waits 2 s for a chooser, and clicks if none opened, and its PASS line names which press opened it. `HX_TEST_CAMERA_PRESS=click` skips the tap so the fallback can be proved on a browser whose tap works. Measured 2026-10-26 on the starter, Chromium 1243: default, opened on tap, 35.0 MB in, 0.21 MB sent; forced click, opened on click, 35.1 MB in, 0.22 MB sent; both runs 0 FAIL, 0 WARN, 36 PASS. Not reproduced here: the tap that sends no click (this container's Chromium sends one), so the failing case itself is his measurement.
