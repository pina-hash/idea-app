## Part 1: items 11 to 14

### What the audit found

- **Item 11 (report 2044c229).** Every grade path funnels into `classroom_grade_submission`
  (0305): the bulk door (`classroom_grade_submissions`, 0175), the team door
  (`classroom_grade_team`, 0305) and the typed-score door (`classroom_grade_direct`, 0242,
  which stores `direct_score` FIRST and then calls it). Revoke and unreturn (0265) write the row
  directly. No setting of any kind restricted an overwrite, so a bulk grade on a post shared with
  IDEA209H Block 4 replaced Mr. Cosso's grades.
- **Item 12 (report 02fd45c0).** `resolveClasses` counted every number in a section's LABEL as a
  block number and let a bare number match "any number in the label or block", so "IDEA209H
  Block 2" also matched Section 2 Block 3, and "209H Block 3" ended up on Section 3 Block 4 when
  the block it named was read through the label. A post title plus a class only narrowed for
  `get_post` and `grading_packet`; `grade`, `read_grades`, `read_answers` and `send_feedback`
  looked the post up with no class at all.
- **Item 13 (gap ba704a08).** No read answered "what is waiting" across classes; it took one
  `read_grades` per post per class.
- **Item 14 (report 6aa5954d).** `read_grades` derived `turned_in` from `submitted_at`, which a
  ported worksheet never sets (no turn-in button, decision 37), so every student was listed under
  `not_turned_in`. The console's roster said "In progress" or "Not submitted" for the same rows.
- Answer history: `classroom_responses` keeps one row per block (primary key item, student,
  block), overwritten on every save. No earlier version exists anywhere. That is item 16's
  starting point (part 2).

### What was built

- **0315** (`supabase/migrations/0315_classroom_grade_protection_and_queue.sql`):
  `classroom_sections.grades_fill_empty_only`, seeded ON for IDEA209H Block 4 only (matched on
  the course code and the block; a guard on the column's own existence means a re-paste never
  re-seeds a switch he turned off); `_classroom_grade_protection_check`, the one rule, called by
  all four grade writes, each re-created as its previous body whole with the 0315 lines marked;
  `classroom_grade_protection_refusals` (table and read) as the list of grades it kept;
  `classroom_set_grade_protection`; `classroom_item_grade_protection` for the console's banner;
  and `classroom_needs_grading`, the one queue read. Signatures, names and grants of the
  re-created functions are unchanged, so there is no deploy ordering.
  - The rule: in a protected class, a grade that exists (graded or returned) and that somebody
    else gave is never changed; an empty one is filled; the caller's own may be corrected (so a
    held fill can be returned). It fails closed: a student in two classes of the post is
    protected if either is; an unknown caller is never the grader.
  - "Exists" deliberately ignores a `direct_score` with no `graded_at`: `classroom_grade_direct`
    stores the typed score a moment before it calls `classroom_grade_submission` in the same
    transaction, and counting that as an existing grade would refuse every first fill.
- **Connector:** `matchClasses` and `parseClassPhrase` in `resolve.ts` (block against block,
  section against section, course-code digits are the course, the exact printed title is that
  class); `class` passed into the post lookup by `read_grades`, `read_answers`, `grade` and
  `send_feedback`; `read_grades` with no post is the needs-grading read with `except` (the tool
  list is at its cap of 45, so this is a new shape of an existing tool, not a 46th);
  `classroom_set_grade_protection`, `classroom_grade_protection_refusals`,
  `classroom_item_grade_protection` and `classroom_needs_grading` as call entries.
- **Worksheet status:** `$lib/classroom/grading-work.ts` (`worksheetAnswered`,
  `worksheetAnsweredWords`) read by the console's roster chip and by the connector's
  `read_grades` and `grading_packet`, which now say `answered`, `questions`, `saved_after_due`,
  `standing` and, at the top, `nothing_answered`, `not_finished`, `saved_after_due` instead of
  `not_turned_in`.
- **Site:** `/classroom/grading` (`GradingQueue.svelte` over `grading-queue.ts`), linked from
  every class's Grades page; the Grades page's Fill empty grades only switch with the grades it
  kept; the grading console's banner naming the protected classes and its refusal sentence
  (`PROTECTED_REFUSAL`, and the bulk report's own line). `grading-extras.ts` is the console's one
  optional transport for everything this ledger adds.
